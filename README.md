# 🛒 E-Commerce Sales Analytics Dashboard

## 📌 Project Overview

This project presents an end-to-end E-Commerce Sales Analytics solution using the Brazilian Olist E-Commerce dataset. The analysis was performed using Google BigQuery, SQL, and Microsoft Power BI to transform raw transactional data into meaningful business insights.

The project focuses on analysing sales performance, customer purchasing behaviour, seller performance, product category trends, and delivery efficiency. Interactive Power BI dashboards were developed to help stakeholders monitor key performance indicators (KPIs) and support data-driven business decisions.

---

## 🎯 Project Objectives

- Analyse overall sales performance.
- Track monthly revenue trends.
- Identify top-performing product categories.
- Evaluate seller performance.
- Analyse customer distribution across states.
- Measure average delivery time.
- Demonstrate advanced SQL techniques using joins and subqueries.
- Build an interactive Power BI dashboard for business reporting.

# 📈 Key Business Insights

- Generated total revenue of over **16 million** across approximately **99,000 customer orders**.
- Achieved an average order value of approximately **154** per transaction.
- Identified the highest revenue-generating product categories and top-performing sellers.
- Analysed monthly revenue trends to understand sales seasonality.
- Evaluated customer distribution across Brazilian states.
- Calculated the average delivery time to assess delivery performance.
- Identified products priced above the average market price using SQL subqueries.
- Identified high-value customers and above-average revenue sellers using advanced SQL analysis.
